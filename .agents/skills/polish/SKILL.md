# Polish (Impeccable)

Perform a final visual polish pass on the existing UI. 
This skill is triggered when the user wants to refine an already built page to make it look "impeccable".

## Checklist
- **Alignment:** Ensure everything is perfectly aligned to the grid.
- **Borders & Radii:** Standardize border radii and ensure borders are subtle but effective.
- **Whitespace:** Increase whitespace to let elements breathe.
- **Colors:** Adjust opacities and muted tones for secondary elements to make primary elements pop.
- **Typography:** Refine line heights and letter spacing.
