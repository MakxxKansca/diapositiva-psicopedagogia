# Web Interface Guidelines

Review files for compliance with Web Interface Guidelines. 
Use when asked to "review my UI", "check accessibility", "audit design", "review UX", or "check my site against best practices".

## Core Principles
- **Spacing:** Use consistent spacing scales. Ensure proper padding and margin for readability and visual balance.
- **Typography:** Maintain a clear typographic hierarchy. Ensure sufficient contrast for text.
- **Interaction:** Interactive elements must have clear hover, active, and focus states.
- **Accessibility:** Ensure all elements are accessible via keyboard and screen readers (ARIA attributes, semantic HTML).

Output findings in a terse file:line format for quick scanning and remediation.
